### 怎么添加入站 / 节点?

进入「节点管理」,点右上角的「添加节点」按钮,在弹出的向导里选服务器、协议、传输/安全后保存即可。系统会同时创建对应的 xray 入站,并自动同步成节点显示在列表里。

### 怎么指定节点出站(给节点配落地)?

在「节点管理」的节点行点双向箭头按钮(⇄),弹出的对话框里既可以选择已有节点作为该节点的出站,也可以选择某台服务器新建一个落地入站(系统会自动配好入站、出站与路由规则)。这是实现链式代理 / 落地中转的入口。

### 怎么开车 / 拼车 给别人开账号?

两步:

1. 建套餐:在「套餐管理」新建一个套餐——设流量额度、重置周期(按月/自定义)、限速(可选)、设备数(可选)、并勾选该套餐包含的节点。

2. 建用户并绑定:在「用户管理」新建用户,绑定刚才的套餐即可。系统会自动给该用户生成订阅链接,他用任意客户端拉这个链接就能看到套餐内的节点。

超额时按套餐配置自动停止返回节点或自动限速(看你怎么配)。

### 我从妙妙屋(mmw)迁移过来,怎么看不到妙妙屋的原有功能?

需要在「系统设置」里把「妙妙屋功能开关」打开。开启后顶部会出现妙妙屋相关菜单(订阅探针、订阅生成等),与妙妙屋X 的服务器管理 / 套餐 / 模板等功能并存。

### 管理员密码忘记了怎么办?

妙妙屋X 不提供任何远程重置管理员密码的渠道(API / 许可证服务 / 远程命令都不行),这是设计上的安全约束 — 任何远程渠道一旦被攻破,所有用户的主控管理员都会沦陷。

正确做法是 SSH 上你的服务器,运行项目提供的本地脚本 reset-admin-password.sh。脚本会自动识别一键安装 / Docker 等部署方式找到数据库,列出 admin 账号让你选择,输入新密码后用 bcrypt 写库并重启服务。

一行命令运行(适用 systemd + Docker 部署):

bash <(curl -fsSL https://raw.githubusercontent.com/iluobei/miaomiaowuX/refs/heads/main/scripts/reset-admin-password.sh)

如果服务器无法访问 GitHub,可以从已下载的 mmwx 源代码中找到脚本:scripts/reset-admin-password.sh,直接 bash 运行。

脚本会:1) 自动探测 mmwx.db(默认 /etc/mmwx/data,Docker 自动找挂载点,均失败时按进程 cwd 兜底);2) 缺 sqlite3 / htpasswd 时自动用 apt / yum / apk 安装;3) 列出所有 active admin,多个让你选;4) 隐藏输入新密码两次确认;5) 自动备份 db(\*.bak-时间戳);6) 写入 bcrypt hash + 顺手禁掉 2FA 防 TOTP 设备同丢;7) 自动重启 mmwx(systemctl restart / docker restart)。

完成后用新密码登录管理面板。登录后建议在「系统设置 → 修改密码」再手动改一次,并新建第二个 admin 账号作为备份。
