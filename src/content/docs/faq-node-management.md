#### 红框 — 添加节点(入站)

打开入站向导对话框。先挑协议(VLESS / Trojan / Shadowsocks / VMess / Hysteria2 / AnyTLS / Tunnel / Socks),再选传输与安全协议组合,简易模式会带你直奔关键字段(REALITY 域名/证书路径等),专家模式右侧实时显示生成的 Xray JSON。

#### 蓝框 — 行内「新增落地节点」

在节点行里点这个按钮,弹出「新增落地节点」对话框:支持三种添加方式 — 直接选另一个节点作落地 / 直接选服务器(自动选其默认 outbound)/ 选负载均衡器(把多个出口打包成一组)。作用范围可选「整个节点共享」或「按用户隔离」。

#### 绿框 — 行内「查看节点路由」

查看该 inbound 当前生效的路由规则。包含两部分:针对此入站的「专属规则」,以及对所有入站生效的「全局规则」。不能在这里编辑全局规则;需要到「自定义规则」页统一管理。

#### 黑框 — Tunnel 管理

集中管理所有服务器上的 tunnel 入站(任意门转发)。tunnel 类型的 inbound 不会出现在节点列表里,删除入口只在这里。常用于把一台机器的某个端口透明地转发到另一台机器的端口,绕过中间网络限制。

#### 黄框 — 路由出站管理(全局)

列出系统中所有「路由出站子节点」,统一查看 / 删除 / 新增。这些 routed 子节点跟物理父节点共用同一个 inbound 凭据,但流量分流到独立的 outbound — 一加入套餐,绑定用户会自动开子账号 + 写 rule.user,实现"按用户路由出站"的高级能力。
