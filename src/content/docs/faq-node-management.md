这一页回答两个最常被问到的问题:**节点怎么建**,以及**建好的节点怎么换出口**。按钮与参数的完整说明见[节点管理](/docs/nodes)。

## 先分清入站和出站

| 名词 | 是什么 | 在哪里操作 |
| --- | --- | --- |
| 入站 | 服务器上对外监听的一个协议端口,客户端连的就是它。**建节点 = 建入站** | 节点管理 →「添加节点」 |
| 出站 | 流量进了这台服务器之后从哪里出去。默认直接从本机出去 | 节点行内的「创建链式出站」,或 服务管理 → Xray 配置 → 出站管理 |
| 节点 | 入站在订阅里的那一条。入站建好后自动出现在节点列表,不用再手动加 | 节点管理 |

所以一般的顺序是:先建节点(入站),需要换出口时再给它配出站。

## 建一个节点

1. 进入「节点管理」,点右上角「**添加节点**」
2. **选择服务器**:选一台显示「Xray 就绪」的服务器,可选用 IPv4 还是 IPv6 作节点地址。服务器多的时候可以用上方的搜索框和分组筛选。右边的「转发链」选项卡是在[转发链](/docs/forward)的入口上建节点
3. **配置入站**:依次选协议、传输协议、安全协议。「简易模式」下端口、UUID / 密码都自动生成,只需要确认;要改端口、监听地址等再切到「专家模式」
4. 点「提交配置」。主控会在服务器上创建入站,节点随即出现在列表里

需要证书的协议(Trojan + TLS、Hysteria2、AnyTLS 等)要求服务器先配好域名与证书,向导会在第一步提示;REALITY、Shadowsocks、Snell 这类不需要证书的可以直接建。各协议能用的组合见[协议矩阵](/docs/protocol-matrix)。

建好之后把节点加进套餐,用户的订阅里就会有它,见[套餐管理](/docs/packages)。

## 让节点从另一台机器出去

在节点那一行点「**创建链式出站**」(双向箭头图标),打开「新增落地节点」。有三种做法:

| 选项卡 | 做什么 | 适合 |
| --- | --- | --- |
| 选择落地节点 | 选一个已有节点(自建的或导入的外部节点)当出口。主控自动在这台服务器上加好出站和路由 | 已经有落地节点 |
| 选择服务器 | 选另一台服务器,主控在那台上新建一个入站当落地,并自动配好出站和路由;也可以直接用这台服务器上已有的出站 | 落地机也是自己管的服务器 |
| 选择负载均衡器 | 把这个入站的流量交给服务器上已配置的负载均衡器,不新建出站、不新建节点 | 已经在 Xray 路由里建了负载均衡器 |

配好之后会多出一个「路由出站」子节点:它和原节点**共用同一个端口和地址**,只是流量从落地出去。原节点不受影响,两者可以分别加进不同的套餐。详见[路由出站](/docs/routed-outbound)。

:::tip[一个线路节点配多个落地]
同一个节点可以重复「创建链式出站」,每选一个落地就多一个子节点 —— 一个入口端口就能同时提供「走香港落地」「走日本落地」等几条线路,适合端口少的 NAT 机器。
:::

### 中转组

如果是反过来 —— 落地节点固定,想让客户端经过**几个中转里最快的一个**再到落地 —— 在落地节点那一行点「**创建中转组**」:选几个中转节点、起个组名,订阅里这个落地节点的 `dialer-proxy` 就会指向这个自动选优的组。

- 别的节点上已经建过的中转组会列在弹窗顶部,点一下就能复用同一个组
- 改一个节点上的组成员时,同名组的其它节点会一起更新
- 这是**客户端一侧**的链式代理(由 Clash 类客户端完成),服务器上不产生转发,所以这段流量不计入套餐用户的用量

## 其它几个常用入口

| 按钮 | 位置 | 做什么 |
| --- | --- | --- |
| 节点路由 | 节点行内(路由图标) | 查看这个入站生效的路由规则:只对它生效的专属规则,以及对所有入站生效的全局规则。见 [Xray 路由管理](/docs/xray-routing) |
| Tunnel 管理 | 右上角 | 管理服务器上的端口转发:把一台服务器的端口转到另一个节点或固定地址,以及给节点换成外部中转的地址。Tunnel 不出现在节点列表里,增删都在这里 |
| 路由出站 | 右上角 | 集中查看、删除所有路由出站子节点 |
| 查看修改配置 | 节点行内(编辑图标) | 重新打开入站向导修改参数;节点 ID 与用户凭据保持不变 |

想把多台服务器编成「入口 → 中转 → 出口」并统一监测,用[转发管理](/docs/forward),而不是逐个建 Tunnel。

## 常见问题

**建完节点,订阅里没有?**
节点要加进套餐、套餐要绑给用户,用户的订阅才会包含它。管理员自己的订阅在「订阅链接」页生成。

**删了节点,入站还在吗?**
自建节点删除时会同时删掉服务器上对应的入站;外部导入的节点只是从列表里移除。节点的修改与删除都会同步到所有订阅。

**落地节点 / 路由出站子节点的流量怎么算?**
流量经过你的服务器,正常按用户计入套餐。只有「中转组」「链式代理」这类由客户端完成的链路,中转那一段不经过你的服务器、无法计量。

**出站管理里「从节点创建出站」和这里的「创建链式出站」有什么区别?**
前者只在服务器上加一个出站,要自己再去路由里写规则把流量指过去;后者一步到位:加出站、写路由、生成子节点。一般用后者。
