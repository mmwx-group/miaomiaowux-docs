MeowX is a standalone proxy client and the officially recommended client for MiaoMiaoWu X. Sign in with your panel account or paste a subscription link to get started; it supports real-time subscription sync, return-route medals and streaming unlock badges from the panel. The version information below is fetched from the latest release, and all downloads are served from `dl.miaomiaowux.com`.

## Installation

### macOS

1. Open the DMG and drag MeowX into Applications. The app is signed with a Developer ID and notarized, so it opens without extra steps.
2. MeowX lives in the menu bar and has no main window: everything is in the drop-down panel behind the menu bar icon.
3. The first connection in System Proxy mode asks for an administrator password to install the helper that changes the system proxy. TUN mode requires allowing the MeowX system extension under System Settings → General → Login Items & Extensions.
4. Apple Silicon (M-series) only.

### Android

1. Download and install the APK (Android may ask you to allow installs from unknown sources).
2. The first connection shows a VPN permission prompt; confirm it.
3. The `mips` network stack is used by default; it can be changed under Me → Advanced.

### Windows

1. The installer is not code-signed, so SmartScreen may show "Windows protected your PC": click "More info → Run anyway".
2. The portable build runs from any folder and keeps its data next to the executable.
3. System Proxy mode works out of the box; TUN mode needs administrator rights and triggers a UAC prompt when the core starts.

### Linux

Supports Ubuntu 22.04 / Debian 12 or later (x64 and arm64), as a deb package or an AppImage:

- **deb package (recommended)**: after downloading, run in a terminal (use the arm64 file name on arm64):

  ```shell
  sudo apt install ./MeowX-*-linux-amd64.deb
  ```

  apt installs the dependencies automatically. Open MeowX from the application menu, or run `meowx` in a terminal. The bundled core already has the permissions it needs, so the virtual network adapter (TUN) under "Takeover" on the home page can be turned on right away. To uninstall: `sudo apt remove meowx`.
- **AppImage**: no installation needed. Run it after `chmod +x MeowX-*.AppImage` (requires FUSE 2: `libfuse2` on Ubuntu 22.04, `libfuse2t64` on 24.04). The AppImage only supports System Proxy mode; TUN is not available.

System Proxy mode sets the proxy for GNOME-based desktops or KDE; for programs that ignore the system proxy, use TUN.

### OpenWrt

Requires OpenWrt 24.10 or later (or the matching ImmortalWrt) with firewall4. The core takes about 40 MB, so on small-flash routers check the free space first with `df -h /overlay`. SSH into the router and run:

```shell
# One-line install: detects the release and architecture, installs the core, service, web UI and translations
wget -O - https://dl.miaomiaowux.com/meowx/openwrt/install.sh | ash
```

Older versions of the install script could print success on some older firmware even though nothing was installed. If MeowX doesn't show up in LuCI after installing, run the command above again: the current script downloads the packages first and stops with an error if any step fails.

To upgrade it later like any system package, add the package feed and install from it instead:

```shell
# Add the feed (once)
wget -O - https://dl.miaomiaowux.com/meowx/openwrt/feed.sh | ash
# OpenWrt 24.10 (opkg)
opkg install meowx luci-app-meowx
# OpenWrt 25.12 or later (apk)
apk add meowx luci-app-meowx
```

Then open LuCI “Services → MeowX”: sign in to your panel account or paste a subscription link under “App Config”, turn on “Enable” and click “Save & Apply”. “Core Only” is on by default (it only runs the core and opens the proxy port, without taking over router traffic); once the subscription works, turn it off and set up the transparent proxy under “Proxy Config”. Uninstall with `wget -O - https://dl.miaomiaowux.com/meowx/openwrt/uninstall.sh | ash` (this removes all settings). See the [GitHub repository](https://github.com/mmwx-group/meowx-openwrt) for more.

The OpenWrt edition is built on the open-source project [OpenWrt-nikki](https://github.com/nikkinikki-org/OpenWrt-nikki) and is released under GPL-3.0.

### fnOS NAS

Requires fnOS (飞牛) with Docker. There is one package for x86 machines and one for ARM.

1. Download the fpk for your architecture above.
2. In fnOS, open “App Center → Manual install” (at the bottom of the sidebar) and upload the fpk. The app runs as a Docker project whose image is built on the NAS itself, so no image registry is needed.
3. Open MeowX from the fnOS desktop, or browse to `http://<NAS address>:7899`. Sign in to your panel account or paste a subscription link on the “Subscriptions” page, then start it on “Overview”.

What you can do with it:

- **Proxy port**: devices on your LAN can set their HTTP / SOCKS5 proxy to `<NAS address>:7890` (one port for both). The LAN and the NAS itself need no password; connections from the internet (through a router port forward) do — the account is under “Mixin”.
- **Transparent proxy**: on the “Transparent proxy” page, turn it on separately for the NAS itself, other containers on the NAS, and LAN devices (side router: set the device's gateway **and** DNS to the NAS address; IPv4 only). After turning it on or changing it there is a trial of a few minutes with a countdown banner at the top: click “Keep settings” once the network works. If you don't, it turns itself off and removes all of its rules, so a mistake can't cut off the NAS (SSH and the web UI included).
- **MeowNest**: after signing in with an admin account you can join the mesh and share the NAS's LAN, see [MeowNest](/docs/en/meownest#fnos-nas).
- **Extras**: po0 allowlisting, GGY allowlisting and the AkileCDN whitelist (on the “Extras” tab from 0.1.2; po0 / GGY used to be on the “Subscriptions” page), see [Extras](/docs/en/client-settings#extras).

To upgrade: from 0.1.1, check for updates under “Settings” in the web UI; the header also tells you when a new version is out. Click “Update now” and MeowX downloads the new package, verifies its sha256 and hands it to the fnOS App Center for an in-place upgrade (the same as App Center's “Manual install”; settings, subscriptions and the MeowNest device identity are kept). It restarts within a minute or two and the page reloads by itself. If the App Center's upgrade interface can't be reached, “Settings” shows a download link for the package instead, and you install it by hand as before. 0.1.0 doesn't have this, so install 0.1.1 by hand once: download the new fpk and use “Manual install”. If fnOS says it is already installed, uninstall it in App Center first — settings, subscriptions and the MeowNest device identity are kept in `/vol1/@appdata/meowx` and survive uninstalling (delete that folder to remove everything).

The web UI has no password by default; if port 7899 of the NAS is reachable from the internet, set one under “Settings”. See the [GitHub repository](https://github.com/mmwx-group/meowx-fnos) for more.

The fnOS edition uses the same core as the OpenWrt edition and is released under GPL-3.0.

## Sign in and import subscriptions

- **Sign in from the web panel** (macOS / Windows): open "Account menu → QR login" in the panel and click "Sign in to client"; MeowX opens and signs in automatically.
- **Scan with your phone** (Android / iOS): show the QR code under "Account menu → QR login" on a desktop browser and scan it with MeowX.
- **Account sign-in** (Linux, also available in the other clients): on the "Me" page click "Account login" and enter the panel address, username and password (plus the verification code if two-step verification is on). The Linux edition does not yet support "Sign in to client" from the web panel.
- **Copy the login link** (OpenWrt / fnOS NAS): routers and NAS boxes can't scan QR codes, so click "Copy login link" under "Account menu → QR login" in the panel and paste it into the "Panel Account" card on the OpenWrt "App Config" page or the fnOS "Subscriptions" page. The link works once, within 5 minutes. On fnOS, if no subscription is in use yet and the account has exactly one, it is imported and switched to automatically.
- **Subscription link**: tap “Import subscription” on the Me page and paste a subscription URL or a MiaoMiaoWu X short link; `clash://install-config` deep links are supported too.

After signing in, "My subscriptions" lists every subscription on the account; tap one to download it and make it active. Changes made in the panel are synced to the client automatically. Signing out removes the subscriptions imported from that panel.

The master needs a public domain and an activated license before clients can sign in. For step-by-step instructions for every sign-in method, prerequisites and troubleshooting, see [Signing in to the Master from the Client](/docs/en/client-login).

## iOS

The iOS build is distributed through TestFlight and is not available for public download yet. You need to apply for the beta on the license server first:

1. Sign in to the [license server](https://license.miaomiaowux.com) and open "Beta signup" in the top menu (or go straight to [license.miaomiaowux.com/beta](https://license.miaomiaowux.com/beta)).
2. Enter your **Apple ID email** (it must be the email of the Apple ID itself — the TestFlight invitation is sent there, and a wrong address never receives it) and your test device (e.g. iPhone 15 / iOS 18), then submit.
3. Once the status changes to "Invited", open the TestFlight invitation link in your mailbox and install MeowX from TestFlight; later updates are delivered through TestFlight as well.

If signups are closed the page says so — watch the community group for announcements. Changing your Apple ID resets the status to "Pending" and a new invitation is sent. The iOS build requires iOS 17 or later; signing in and importing subscriptions work the same way as on Android (scan the QR code with your phone or paste a subscription link).
