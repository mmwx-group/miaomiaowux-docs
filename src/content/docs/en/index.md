## Differences from MiaoMiaoWu

### Remote Server Management

Master-Agent architecture for managing multiple remote servers via WebSocket/HTTP

### Full Xray Management

Visual management of inbound/outbound/routing/system configuration

### Certificate Management

ACME auto certificate issuance with multi DNS provider support, auto-deployed to remote servers

### Package Management

Traffic package configuration with user traffic quota management
