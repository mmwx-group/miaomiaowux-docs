## Core features

<CardGrid stagger>
  <Card title="Remote servers" icon="laptop">
    Master-Agent architecture, one-click Agent install, WebSocket / HTTP / Pull
    connections, start / stop Xray and Nginx from the card, upgrade Agents
    remotely. [Remote Servers →](/docs/en/remote-servers)
  </Card>
  <Card title="Nodes & inbound wizard" icon="setting">
    VLESS / VMess / Trojan / Shadowsocks / Hysteria2 / AnyTLS / Snell / Mieru —
    pick protocol, transport and security to generate an inbound that syncs to a
    node automatically. [Node Management →](/docs/en/nodes)
  </Card>
  <Card title="Protocol reference" icon="open-book">
    The full protocol × transport × security matrix, each protocol with wizard
    screenshots and Xray config examples. [Protocol Matrix
    →](/docs/en/protocol-matrix)
  </Card>
  <Card title="Certificates" icon="approve-check">
    ACME issuance and renewal with Cloudflare / Alibaba / Tencent / Namesilo,
    auto-deployed to every server that uses the certificate; upload or webhook
    also supported. [Certificates →](/docs/en/certificates)
  </Card>
  <Card title="Users & packages" icon="star">
    Packages define traffic, cycle, speed limits and node scope; users can hold
    several packages, copy subscriptions in one click, bind Telegram and use the
    Mini App. [User Management →](/docs/en/users)
  </Card>
  <Card title="Subscriptions & templates" icon="document">
    12+ client formats, V3 templates with include-all / filter so new nodes join
    subscriptions automatically, override rules for fine-grained splitting.
    [Subscription Generator →](/docs/en/generator)
  </Card>
</CardGrid>
