### Subscription link won't open or nodes are empty?

Check: 1) Is the Token correct? 2) Is the user bound to a package? 3) Are there available nodes? 4) Are nodes disabled?

### Trojan nodes won't connect in mihomo?

In mihomo, Trojan uses the sni field instead of servername. The system handles this automatically. If issues persist, check if the certificate domain matches.
