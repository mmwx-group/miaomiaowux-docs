妙妙屋X 是妙妙屋的增强版本，继承了妙妙屋的全部核心功能（订阅生成、模板系统、自定义规则等），并在此基础上新增了远程服务器管理、Xray 完整管理、证书管理、套餐管理等企业级功能。

简单来说：妙妙屋是订阅管理平台，妙妙屋X 是完整的代理服务管理平台。以下是详细的功能对比。

## 功能对比总览

| 功能维度 | 妙妙屋 | 妙妙屋X |
| -------- | ------ | ------- |

|
流量管理

| 探针读取流量，无法精确统计 | Agent 精确统计，到期自动失效 |
|

节点管理

| 手动导入 / 外部订阅同步 | 页面创建 + 偷自己 / 路由出站 / Tunnel |
|

用户管理

| 基础用户管理，到期后本地配置仍可用 | 套餐绑定，到期自动删除节点权限 |
|

服务器管理

| 不支持 | Master-Agent 远程管理 |
|

证书管理

| 不支持 | ACME 自动申请 / 续期 / 部署 |
|

套餐管理

| 不支持 | 流量配额 / 有效期 / 限速 |
|

监控探针

| 探针流量采集，节点级监控 | 精确流量统计 + 实时在线用户追踪 |
|

订阅生成

| 12+ 客户端格式 | 12+ 客户端格式（继承） |
|

| V3 模板引擎 | V3 模板引擎（继承） |
|

自定义规则

| DNS / 分流 / 规则集 | DNS / 分流 / 规则集（继承） |
|

安全功能

| 静默模式 / TOTP 双因素 | 静默模式 / TOTP 双因素（继承） |
|

部署方式

| Docker / 二进制 | Docker / 二进制（Master + Agent） |

## 流量管理

### 妙妙屋

- •通过探针系统读取节点流量数据
- •仅能统计节点级别的流量，无法精确到用户
- ✗用户到期后，由于未修改节点信息，本地已有的订阅配置仍然可以使用

### 妙妙屋X

- 在服务器安装 MMW-Agent，直接管理 Xray 服务的用户和流量
- 精确统计每个用户、每个节点的流量使用量
- 用户到期时自动删除节点访问权限，订阅中的凭据立即失效
- 支持流量配额、限速、设备数限制，到期自动封禁

## 节点管理

### 妙妙屋

- •支持用户手动添加节点（填写节点信息）
- •支持通过外部订阅链接同步节点
- •支持链式代理、节点分组、排序等基础管理
- ✗如需在服务器新增节点，只能手动登录服务器配置后再导入妙妙屋

### 妙妙屋X

- 通过页面创建各种协议节点（VLESS/VMess/Trojan/SS/Hysteria2），19 种协议组合一键配置
- 偷自己：复用已有入站配置，快速创建新节点
- 路由出站：支持中转节点复用，实现流量分流和多层转发
- 端口转发 Tunnel（dokodemo-door）：在已有服务器创建出站，指定节点为出站目标
- 大部分 Xray 配置需求都可以通过页面点击完成，无需登录服务器

## 用户管理

### 妙妙屋

- •创建用户、分配订阅文件、管理用户状态
- •支持设置用户有效期，但到期后需要手动处理
- ✗用户到期后本地配置仍可继续使用（节点信息未变更）

### 妙妙屋X

- 用户绑定套餐，套餐控制流量配额、有效期、可用节点
- 到期自动删除用户的节点访问权限，凭据即时失效
- 支持限速和设备数限制，超出自动限制
- 精确的流量统计和在线用户追踪

## 服务器管理

### 妙妙屋

妙妙屋不提供服务器管理功能。所有节点配置需要手动在服务器上完成后导入系统。

### 妙妙屋X

- Master-Agent 架构：主控端通过 WebSocket/HTTP/Pull 管理远程服务器
- 远程安装/卸载 Xray 和 Nginx，SSE 流式安装进度
- 可视化管理 Xray 入站、出站、路由配置
- Agent 远程在线升级和卸载，无需登录服务器
- 共享服务器功能：加密通信（HTTPS + ECDH），多用户协作管理

## 妙妙屋X 独有功能

### 内嵌 Xray (PRO)

内置 Xray 核心，支持限速、设备数限制、自动限流、在线追踪等高级功能。无需单独安装 Xray，热更新能力。

### 路由出站

支持整节点级别和单用户级别的出站路由配置。落地节点和中转节点概念，灵活的流量转发策略。

### 共享服务器

Owner-Consumer 模型，加密通信（HTTPS + ECDH），Consumer 拥有受限权限（添加入站、管理节点，但无法启停服务或编辑服务器）。

### 证书管理

ACME 自动申请和续期 TLS 证书，支持 Cloudflare/阿里云/腾讯云/Namesilo 等 DNS 提供商，自动部署到远程服务器。

### 套餐管理

创建流量套餐，配置流量配额、有效期、可用节点、限速策略，绑定到用户后自动管理。

### Nginx 管理

远程安装/卸载 Nginx，管理配置文件，SSL 证书部署，Stream 端口管理。

## 共同功能

妙妙屋X 继承了妙妙屋的全部核心功能，以下功能在两个版本中完全一致：

支持 12+ 客户端格式的订阅生成（Clash/Surge/Shadowrocket/Loon/QX 等）

V3 模板引擎，灵活的订阅配置模板

自定义 DNS、分流规则、规则集管理

外部订阅同步（定时自动更新）

链式代理（多层中转加速）

静默模式和 TOTP 双因素认证

Telegram 通知推送和每日报告

备份与恢复功能

覆写脚本（JavaScript Hooks）

Docker 和二进制部署方式

## 总结

如果你只需要管理订阅和节点导入，妙妙屋已经足够满足需求。它简单轻量，适合个人使用。

如果你需要管理多台远程服务器、精确控制用户流量和权限、自动化证书管理，或者需要通过页面配置 Xray 而无需手动登录服务器，那么妙妙屋X 是更好的选择。妙妙屋X 的大部分功能都继承自妙妙屋，升级迁移非常简单。
