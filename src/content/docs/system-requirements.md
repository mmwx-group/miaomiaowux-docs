## 主控端要求

| 项目     | 要求                          |
| -------- | ----------------------------- |
| 操作系统 | Linux (amd64/arm64) / Windows |
| 内存     | 128MB+                        |
| 磁盘     | 100MB+（含数据库）            |
| 端口     | 12889（默认，可配置）         |

## Agent 端要求

| 项目     | 要求                                                      |
| -------- | --------------------------------------------------------- |
| 操作系统 | Linux (amd64/arm64)                                       |
| 内存     | 64MB+                                                     |
| 端口     | 23889（Agent API，默认）                                  |
| 网络     | 能访问主控端（WebSocket 模式）或被主控端访问（HTTP 模式） |

## 防火墙端口

| 端口   | 用途                           | 位置       |
| ------ | ------------------------------ | ---------- |
| 12889  | 主控端 Web 面板和 API          | 主控端     |
| 23889  | Agent API（HTTP 模式需要）     | 远程服务器 |
| 443    | TLS/REALITY 入站（Nginx 伪装） | 远程服务器 |
| 自定义 | Xray 入站端口                  | 远程服务器 |
