订阅文件管理 — 列出所有订阅模板,可绑定 V3 模板、选择节点、设置短链

## 概述

订阅文件功能允许从外部订阅链接导入节点，与本地 Xray 入站生成的节点合并，统一通过订阅系统分发。

## 支持的订阅格式

- \- Clash/mihomo YAML 格式
- \- Base64 编码的节点列表
- \- 单行 URI 格式（ss://, vmess://, vless://, trojan://）

## 添加订阅

1\. 进入「订阅文件」管理页面

2\. 点击「添加订阅」

3\. 填写订阅名称和 URL

4\. 设置自动更新间隔（可选）

5\. 保存后系统自动拉取并解析节点

## 自动更新

可为每个订阅设置自动更新间隔。系统会定期拉取最新订阅内容，自动更新节点列表。

| 更新间隔 | 适用场景           |
| -------- | ------------------ |
| 手动     | 节点稳定，不常变更 |
| 每小时   | 节点频繁变更       |
| 每天     | 一般使用           |
| 自定义   | 按需设置           |

## 注意事项

- \- 导入的节点与本地入站节点合并输出
- \- 可对导入节点进行启用/禁用、重命名操作
- \- 订阅 URL 变更后需手动触发一次更新
