订阅管理 — 上方「订阅列表」是生成的订阅文件，下方「外部订阅」是从节点管理导入的第三方订阅源

## 概述

「订阅管理」页面管理两类东西：

- **订阅列表**：在 [生成订阅](/docs/generator) 页面保存的订阅文件（subscribes 目录下的 YAML）。每个文件可以设置自定义短链、绑定 V3 模板、查看流量。
- **外部订阅**：在 [节点管理 → 导入外部节点 → 订阅导入](/docs/nodes#导入外部节点) 导入的机场订阅源。这里可以查看、手动同步或删除，导入的节点会与本地 Xray 入站生成的节点合并，统一通过订阅系统分发。

页面顶部的「聚合订阅」可以把几个外部订阅按标签合成一个新订阅，见下文 [聚合订阅](#聚合订阅)。

## 订阅列表

| 列         | 说明                                                                                       |
| ---------- | ------------------------------------------------------------------------------------------ |
| 订阅名称   | 保存时填写的名称                                                                           |
| 创建用户   | 生成该文件的用户；管理员可用上方下拉筛选                                                   |
| 最后更新   | 文件最近一次生成 / 重新生成的时间                                                          |
| 自定义链接 | 该文件的短码，点击复制 `/x/<短码>` 订阅地址，也可编辑成自定义短码                          |
| V3 模板    | 为该文件绑定一份 V3 模板，绑定后下载时按模板动态生成，新增节点自动进订阅                   |
| 流量       | 该订阅对应的已用 / 限额进度，可上下箭头调整显示限额                                        |
| 操作       | 设置（节点范围 / 标签筛选等）、编辑内容、删除                                              |

## 支持的外部订阅格式

- Clash/mihomo YAML 格式
- Base64 编码的节点列表
- 单行 URI 格式（ss://, vmess://, vless://, trojan://）

## 添加外部订阅

外部订阅在「节点管理」页面导入：

1. 进入「节点管理」，展开「导入外部节点」→「订阅导入」
2. 填写订阅 URL，选择 User-Agent，可选填节点标签
3. 点「导入节点」，系统拉取并解析节点，确认后「保存节点」
4. 回到「订阅管理」，在「外部订阅」区块可以看到这条订阅源

## 自动更新

外部订阅可设置自动更新间隔。系统会定期拉取最新订阅内容，自动更新节点列表；「系统设置 → 订阅」里还可以配置节点名称过滤正则、追加订阅信息、同步流量信息、掉线自动重同步等，见 [系统设置](/docs/system-settings)。

| 更新间隔 | 适用场景           |
| -------- | ------------------ |
| 手动     | 节点稳定，不常变更 |
| 每小时   | 节点频繁变更       |
| 每天     | 一般使用           |
| 自定义   | 按需设置           |

## 聚合订阅

聚合订阅把几个外部订阅（或任意节点标签）合成一个新订阅。它只记住「要哪些标签」，不保存节点：每次客户端获取订阅时，按标签实时取当前的节点。源订阅的节点从 100 个变成 20 个，聚合订阅也跟着变成 20 个，不用重新生成。

适合把几个机场订阅合并成一份给自己用，或者把外部订阅和自家节点放进同一份配置。

### 创建

1. 在「订阅管理」页顶部点「聚合订阅」。
2. 填「订阅名称」；「说明」和「文件名」可留空自动生成。
3. 在「源订阅 / 标签」里勾选要合并的来源：
   - **外部订阅**：外部订阅同步进来的节点，以订阅名作为标签。
   - **节点标签**：其他节点标签，例如导入外部节点时手填的标签。
4. 「绑定模板」可选：
   - 不绑定模板：生成精简配置，所有节点放进一个手选组 `PROXY`（外加直连），全部流量走这个组。
   - V3 模板：按模板生成，带分流规则。
   - 我的 V2 模板 / V2 预设模板：先转换成 V3 模板文件再绑定（同名的 V3 模板已存在就直接用），之后可以在 [模板](/docs/templates) 页继续编辑。
5. 点「创建聚合订阅」。

![创建聚合订阅对话框截图](../../assets/screenshots/subscribe-aggregate-create.webp)

创建聚合订阅：勾选「机场A」「机场B」两个外部订阅作为来源，绑定 V3 模板 default

![绑定模板下拉列表截图](../../assets/screenshots/subscribe-aggregate-template.webp)

「绑定模板」可选不绑定、V3 模板，或 V2 预设模板（选中后先转换成 V3 模板文件再绑定）

还没有可选的标签时，先在 [节点管理](/docs/nodes#导入外部节点) 导入外部订阅，或给节点打上标签。

### 与普通订阅的区别

- 订阅列表里带「聚合」标记，鼠标悬停可看到来源标签。
- 没有「编辑配置」和「选择节点」：内容由标签决定。「编辑信息」里可以改选来源标签。
- 节点取自**创建者自己**的节点（通常就是本人导入的外部订阅），不受套餐范围限制。
- 生成方式与绑定模板的订阅相同：面板节点照常换成收件人自己的凭据，转发链、WireGuard 等照常处理。
- 生成失败（例如所选标签下一个节点都没有）时直接返回错误，不会下发一份空配置。

![订阅列表里的聚合订阅截图](../../assets/screenshots/subscribe-aggregate-list.webp)

聚合订阅在列表里带「聚合」标记，鼠标悬停显示来源标签

![编辑聚合订阅信息截图](../../assets/screenshots/subscribe-aggregate-edit.webp)

「编辑信息」里可以改选来源标签；没有「编辑配置」和「选择节点」

### 让源订阅删掉的节点也跟着消失

外部订阅同步时默认只更新已保存的节点，源里新增的节点不会自动加入，源里删掉的节点也不会删除。想让聚合订阅完整跟随源订阅，把「系统设置 → 订阅 → 外部订阅同步设置」里的 [同步范围](/docs/system-settings#同步范围) 设为「同步所有节点」：新节点自动加入，源里已经没有的节点在同步时删掉（某次更新失败时不会删）。

## 流量列

管理员看到所选统计服务器（未选择时为全部服务器）的汇总；仅通过 `selected_tags` 命中的外部订阅会按自身 upload/download/both 规则加入。普通用户只看到自己创建的文件：限额来自主套餐，用量聚合该用户全部套餐凭据，且不加入外部订阅。文件限额可以覆盖显示限额。完整口径见[流量统计口径](/docs/traffic-accounting)。

## 注意事项

- 导入的节点与本地入站节点合并输出
- 可对导入节点进行启用/禁用、重命名操作
- 订阅 URL 变更后需手动触发一次更新
