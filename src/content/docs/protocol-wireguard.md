## 概述

WireGuard 是基于 UDP 的隧道协议，自带加密，不需要证书，也没有传输层和安全层可选。妙妙屋X 在嵌入式 xray 内核中提供 WireGuard 入站：服务端密钥、隧道地址池和每个用户的密钥都由主控分配，建节点时不需要手填任何密钥。

| 项目     | 说明                                                                            |
| -------- | ------------------------------------------------------------------------------- |
| 鉴权     | 每个用户一对独立的密钥，外加一组隧道内地址（IPv4 + IPv6）                       |
| 传输     | UDP                                                                             |
| 安全层   | 无（协议自身加密，不需要证书）                                                  |
| 内核要求 | 只有 [嵌入式 xray](/docs/embedded-xray) 的服务器支持，外置（官方）xray 上不可选 |
| 版本要求 | 主控 v0.5.5 及以上                                                              |

## 添加节点（向导）

在「节点管理 → 添加节点」选择 WIREGUARD。表单里只有一项：

- **MTU**：隧道的最大传输单元，范围 1280–1500，默认 1420，一般不用改。

服务端密钥与隧道地址由主控分配，用户凭据在绑定套餐时逐个下发，都不需要填写。防火墙要放行这个入站的 **UDP** 端口。

把节点绑进套餐后，套餐里的每个用户会拿到自己的密钥和隧道地址，订阅里下发的是各自的凭据。用户被移出套餐时，他的密钥和地址会被收回。

## 限制

- **不能与其它协议互换**：编辑节点时不能在 WireGuard 和别的协议之间切换（地址池与用户的地址租约无法迁移），需要另建一个入站。
- **只能在「节点管理」里编辑**：在「Xray 入站」页直接编辑 WireGuard 入站会被拒绝，那里的编辑是先删后加，会清掉地址池并换掉服务端密钥。
- **不支持转发链**，也不能用作端口转发（Tunnel）的源、落地出口或转发链的终点。
- 服务器没有 IPv6 时，订阅里不会下发 IPv6 隧道地址。
- 服务器从内嵌 xray 切换到外置 xray 前，必须先删掉上面的 WireGuard 入站。
- 管理员「重置用户凭据」会一并更换该用户的 WireGuard 密钥，用户更新一次订阅即可继续使用。

## 客户端兼容性

订阅里生成的是 mihomo 的 `type: wireguard` 节点。mihomo / Clash.Meta 系客户端可以直接使用；转换成其它客户端格式时，不支持 WireGuard 的客户端会跳过这类节点。

:::note
这里说的是把 WireGuard 当作一种**代理节点**提供给用户。面板里另外两处也用到了 WireGuard，但与本页无关：[反向隧道](/docs/reverse-tunnel)（服务器之间的内网隧道）和 [WARP 出站](/docs/xray-outbounds)。
:::

## 配置示例

订阅中生成的 mihomo 节点（密钥与地址每个用户不同）：

```yaml
- name: 东京 WireGuard
  type: wireguard
  server: 203.0.113.10
  port: 51820
  ip: 10.66.0.2
  ipv6: fd00:1234:5678::2
  private-key: <用户私钥>
  public-key: <服务端公钥>
  udp: true
  mtu: 1420
```
