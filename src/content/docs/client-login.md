MeowX 客户端（iOS / macOS / Android / Windows / OpenWrt）可以直接登录面板账号。登录后客户端会列出账号下的全部订阅，点一下即可导入；面板改了节点或订阅，客户端会自动同步，不用再手动复制订阅链接。

只想用订阅、不登录也可以：把订阅链接粘贴到客户端里即可，这种方式不需要下面「主控要先准备什么」里的任何条件。

本页先讲管理员要做的准备，再讲用户怎么登录，最后是常见问题。客户端的下载与安装见 [客户端下载](/docs/client-download)，设置项见 [客户端设置](/docs/client-settings)。

## 主控要先准备什么

客户端和主控之间走的是一条独立的加密通道（见下文 [安全机制](#安全机制)），不是网页那套登录。这条通道要靠主控的 **客户端身份证书** 才能建立：**主控拿不到证书时，客户端用哪种方式都登录不了**，账号密码登录也一样。

证书由主控自动向许可证服务申请，管理员只需要保证下面四个条件：

| 条件 | 在哪里设置 | 说明 |
| --- | --- | --- |
| 填好主服务器地址 | 系统设置 →「系统」→「主服务器地址」 | 填对外的 HTTPS 域名，例如 `https://panel.example.com`。证书绑定的就是这个域名，客户端也只连这个域名，详见 [主控域名](/docs/domain-master) |
| 激活许可证 | 系统设置 →「许可证」 | 证书由许可证服务签发，未激活许可证的主控没有客户端登录功能（订阅链接不受影响） |
| 域名没被别的许可证占用 | — | 同一个域名只能绑定在一份许可证名下。换过许可证或把域名借给过别的主控时可能遇到，换一个域名或联系支持解绑 |
| 外部能访问 `/api/secure/*` | 反向代理 / CDN / 隧道 | 客户端要用到 `/api/secure/cert`、`/api/secure/rpc`（二进制 POST）和 `/api/secure/ws`（WebSocket），三条都要能从外网经 HTTPS 443 端口直达主控 |

### 为什么一定要 HTTPS 和 443 端口

网页生成的登录二维码 / 登录链接里，主控地址固定写成 `https://` 加证书域名，**不带端口**。所以客户端总是去连 `https://你的域名`（443 端口）：

- 主服务器地址填了 `http://` 或带了非 443 端口，扫码登录会连不上。
- 主控放在 Nginx、Cloudflare 或 [Cloudflare Tunnel](/docs/cloudflare-tunnel) 后面时，要确认这个域名的 443 端口能到达主控**全部路径**，不能只转发订阅路径。WebSocket 也要放行，否则登录成功后收不到实时同步。
- 不要只填「订阅域名」而不填主服务器地址：订阅域名常常是只代理订阅路径的 CDN，证书会签到它上面，客户端随后连过去找不到 `/api/secure/*`。

### 证书的签发与续期

管理员不用手动操作：

- 第一次有客户端（或网页的扫码登录窗口）来取证书时自动签发，有效期 30 天。
- 主控启动 2 分钟后开始检查，之后每 6 小时检查一次，剩余不足 5 天时自动续期。续期失败而旧证书仍有效时，继续用旧证书。
- 签发失败后会自动重试，间隔从 30 秒逐步拉长到 30 分钟。改好设置后最多等这么久，或者重启主控立即重试。

### 怎么确认证书正常

在浏览器打开 `https://你的域名/api/secure/cert`：

| 看到的内容 | 说明 |
| --- | --- |
| 一段 JSON，含 `domain`、`masterPub`、`expireUnix` | 证书正常，`domain` 应与主服务器地址的域名一致 |
| `{"error": "..."}` | 主控拿不到证书，原因写在 `error` 里，对照下文 [常见问题](#常见问题与排查) |
| 一个 HTML 页面、404 或 Cloudflare 拦截页 | 请求没到主控：反向代理 / 隧道没有放行 `/api/secure/*` |

另一个简单的检查：用管理员账号打开面板右上角头像菜单 →「扫码登录手机」。证书有问题时，这个窗口会直接提示「主控还没有可用的客户端身份证书，扫码登录会失败」并说明原因，不会生成二维码。

## 登录方式

五种方式，按设备选：

| 方式 | 从哪里开始 | 适合 | 需要两步验证码 |
| --- | --- | --- | --- |
| [账号登录](#账号登录) | 客户端里输入主控地址、用户名、密码 | 所有平台 | 开了两步验证就要 |
| [扫码登录](#扫码登录) | 网页出示二维码，手机客户端扫 | Android / iOS | 不需要 |
| [网页一键登录](#网页一键登录登录客户端) | 网页点「登录客户端」唤起本机客户端 | macOS / Windows，也可在手机浏览器里用 | 不需要 |
| [复制登录链接](#复制登录链接) | 网页复制链接，粘贴到设备上 | OpenWrt 等不能扫码的设备 | 不需要 |
| [Telegram Mini App](#telegram-mini-app-登录) | 机器人 Mini App 里点「登录客户端」 | 绑定了 Telegram 的用户 | 不需要 |

后四种用的是同一种一次性登录码，规则相同：

- **5 分钟内有效、只能用一次**，用过即作废；过期了点「重新生成」。
- 登录码只存在主控内存里，**主控重启后全部作废**。
- 不需要两步验证码：已经在网页上登录的你就是授权人。也因此**不要把二维码或登录链接发给别人**，谁在 5 分钟内用了它，谁就登录成了你的账号。

### 账号登录

1. 打开 MeowX 的「我的」页（macOS 在菜单栏面板里），点「账号登录」。
2. 「主控地址」填主服务器地址，例如 `https://panel.example.com`；再填用户名和密码。
3. 账号开了两步验证时，会再要求输入「验证码 / 恢复码」：填验证器 App 上的 6 位验证码，或一个备用恢复码。

账号密码登录不受网页人机验证（Turnstile）影响，但受 [登录限流](#登录被锁定) 约束。

### 扫码登录

1. 在电脑上登录面板，点右上角头像 →「扫码登录手机」，窗口里出现二维码和倒计时。
2. 打开手机上的 MeowX，在「我的」页点「扫码登录」，对准二维码。
3. 客户端登录成功后关掉网页窗口即可（网页不会自动感知手机已登录）。

如果二维码下方提示「手机将连接 某域名（主控对外地址），与当前面板地址不同是正常的」：说明你当前是用别的地址（IP、内网地址等）打开面板的，手机会去连主服务器地址，这是预期行为。

### 网页一键登录（「登录客户端」）

适合在已经装了 MeowX 的这台电脑上登录：

1. 打开「扫码登录手机」窗口，点「登录客户端」。
2. 浏览器会询问是否打开 MeowX，允许后客户端自动完成登录。

点了之后约 1.5 秒还停在网页上，会提示「未检测到 MeowX 客户端」：确认本机已安装 MeowX，或者浏览器拦截了打开应用的请求（换个浏览器、或允许该站点打开外部应用）。

### 复制登录链接

给 OpenWrt 路由器这类既不能扫码、也唤不起客户端的设备用：

1. 在「扫码登录手机」窗口点「复制登录链接」。复制失败时链接会显示在窗口下方的输入框里，手动复制即可。
2. 5 分钟内把链接粘贴到设备的 MeowX 里。OpenWrt 版在 LuCI「服务 → MeowX」→「插件配置」→「主控账户」卡里粘贴。

登录链接形如 `miaomiaowu://login?host=https://panel.example.com&code=…`，其中 `host` 是主服务器地址，`code` 是一次性登录码。

### Telegram Mini App 登录

面板配置了 Telegram 机器人、用户已在面板里绑定了 Telegram 账号时可用：

1. 在 Telegram 里打开机器人的 Mini App，首页有一张「MeowX 客户端」卡片，点「登录客户端」。
2. Telegram 内置浏览器打不开自定义链接，所以会跳到一个「正在打开 MeowX」的中转页，再点页面上的「打开 MeowX 客户端」。
3. 仍然打不开时，先确认本机装了 MeowX，再用浏览器菜单里的「在 Safari / 浏览器中打开」再试一次。

提示「该 Telegram 账号未绑定面板账号」时，先在面板里完成 Telegram 绑定。

## 登录之后

### 我的订阅

客户端里「我的订阅」会列出账号下的全部订阅，点一下即下载并切换为当前配置：

- 普通用户：管理员分配的订阅、套餐订阅、自己创建的订阅，以及合并订阅。
- 管理员：全部订阅文件，加上自己名下的套餐。

账号下只有一份订阅、本机又还没导入过这个主控的订阅时，部分平台会自动导入那一份。

### 自动同步

登录后客户端和主控之间保持一条加密的长连接。管理员改了节点、套餐或订阅，主控会立即通知客户端重新拉取；连接断开期间客户端也会定期检查更新。[转发](/docs/forward) 入口的健康列表也经这条连接推给客户端，入口切换不用等 DNS 生效。

每个账号同时最多 16 条这样的长连接，网页标签页也算在内。一个人几台设备加几个网页标签页一般不会碰到上限。

### 登录有效期与退出

- 一次登录有效 **30 天**，到期不会自动续，客户端会提示会话已失效，重新登录即可。
- 客户端里点「退出」时，会**先删掉从这个主控导入的订阅**，再清掉登录信息（保留主控地址，方便下次登录）。
- 登录过期时客户端只清掉登录信息、**不删订阅**，正在用的配置照常可用，重新登录即可恢复同步。
- 退出只在本机生效，主控那边的会话要到期才失效。需要立刻让某人在所有设备上下线时，在「用户管理」里**停用该用户**：主控会撤销他的全部登录、断开他所有客户端的连接。管理员修改自己的管理员凭据时，主控会让全站所有登录失效。目前不支持按单台设备踢下线。

### 登录通知

在系统设置的通知里打开「登录通知」后，每次有人登录（包括客户端登录）都会推送用户名和 IP 地址。

## 安全机制

客户端不用网页登录那一套，而是和主控之间建立一条独立的加密通道：

- **防冒充**：主控的客户端身份证书由许可证服务签发，绑定了主控的域名和一把专用公钥。客户端连接前会校验证书签名，并核对证书域名与它要连的域名是否一致，不一致就拒绝连接。别人搭的假主控、或被劫持的连接，拿不出这张证书。
- **防窃听、防重放**：每个请求都用一次性的临时密钥加密，请求里带时间戳和随机数。主控只接受与自己时间相差 **2 分钟以内** 的请求，同一个请求不能重放。所以**手机时间不准也会登录失败**。
- **权限收窄**：经这条通道只能访问登录、订阅和普通用户接口，任何管理接口都不开放。即使客户端设备丢失，拿到的也只是普通用户能做的事。
- 网页的人机验证（Turnstile）不作用于客户端登录；但 [登录限流](#登录被锁定) 照常生效，扫码兑换登录码也受限流保护。

## 常见问题与排查

### 网页提示「主控还没有可用的客户端身份证书」

扫码登录窗口打不出二维码，并给出原因：

| 原因 | 处理 |
| --- | --- |
| 未配置对外域名 | 在「系统设置 →「系统」→「主服务器地址」」填对外 HTTPS 域名 |
| `license is not configured` | 激活许可证 |
| `certificate domain is claimed by another license` | 这个域名已经绑定在另一份许可证名下，换一个域名，或联系支持解绑 |
| 其他签发失败（许可证服务连不上等） | 主控会自动重试（最长间隔 30 分钟）；检查主控能否访问外网，或稍后重启主控再试 |

### 客户端提示「无法获取主控证书（HTTP 4xx / 5xx）」

客户端连上了这个域名，却没取到证书。常见原因：

- 反向代理、CDN 或 Cloudflare Tunnel 没有把 `/api/secure/*` 转发给主控（返回了 404 或拦截页）。按上文 [怎么确认证书正常](#怎么确认证书正常) 用浏览器打开检查。
- 客户端里填的主控地址不是主服务器地址（例如填了订阅域名、IP 或内网地址）。改成主服务器地址的域名。
- 主控的证书本身没签出来（见上一条）。

### 「主控证书域名不匹配」或「主控证书已过期」

客户端会核对证书域名与它连接的域名。用 IP、别的域名或内网地址登录时会被拒绝：账号登录请把「主控地址」改成主服务器地址；改过主服务器地址后，旧的二维码 / 链接作废，重新生成即可（证书会按新域名重签）。

「已过期」一般是主控长时间续期失败（许可证失效、主控连不上许可证服务），按 [网页提示「主控还没有可用的客户端身份证书」](#网页提示主控还没有可用的客户端身份证书) 一节 排查后重启主控。

### 「二维码已失效，请重新生成」

登录码过期（超过 5 分钟）、已经用过、或主控在这期间重启过。回到网页窗口点「重新生成」。

### 「invalid credentials」

用户名或密码错误，或者该账号已被停用。

### 登录被锁定

提示 `too many login attempts, please try again later`：同一 IP 或账号失败次数太多，触发了登录限流。默认是 60 分钟内失败 5 次，锁定 60 分钟。

- 管理员可以在「日志管理 →「安全日志」」的「登录锁定」列表里点「解除」。
- 阈值在「系统设置 →「安全」→「登录限流」」调整（最大尝试次数 / 统计窗口 / 锁定时长）。

### 「stale request」或登录总是莫名失败

手机或电脑的时间与主控相差超过 2 分钟。打开系统的「自动设置时间」后重试；主控服务器的时间也应保持同步。

### 两步验证码不对

提示 `invalid 2FA code`：检查验证器 App 的时间是否准确，或改用备用恢复码；提示 `invalid or expired 2FA token` 说明输入验证码超过了 5 分钟，重新输入密码登录。

### 开了「关闭公网访问」

开启后，用主服务器地址以外的地址访问主控会被跳转到主服务器地址。客户端按上文填主服务器地址的域名即可正常登录。详见 [主控域名](/docs/domain-master)。
