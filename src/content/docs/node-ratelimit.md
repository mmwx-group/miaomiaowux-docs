## 概述

节点限速允许管理员为每个套餐配置下载速度上限和最大并发连接数。当用户绑定套餐后,限速规则会自动推送到该用户关联的所有入站上,由内嵌 Xray 内核在流量层面实施限制。

节点限速是 PRO 功能，需要有效的许可证。且限速仅在内嵌 Xray 模式的服务器上生效，外置 Xray 模式不支持限速推送。

## 工作原理

```
套餐配置 (speed_limit_mbps / device_limit)
     │
     ▼
主控查询用户关联的入站 (inbound tags)
     │
     ▼
为每个入站构建限速规则 (WSLimiterConfigPayload)
     │
     ▼
通过 WebSocket 推送到内嵌 Xray Agent
     │
     ▼
Agent 在 Xray 内核层面实施速度和设备限制
```

## 连接数限制怎么理解

这里的“连接数”指的是同一时刻正在代理的网络连接数量,不是设备数量。一个设备会同时开很多条连接——所以它是一个防止账号被大量共享/转卖的粗粒度上限,而不是精确的“允许几台设备”。

- 打开一个网页 ≠ 一条连接:浏览器会同时向主域名、CDN、字体、统计、广告等几十个主机各开若干条连接,一个页面加载的瞬间常有 10–50+ 条并发连接;加载完空闲连接会陆续释放,数字回落。
- 看视频、刷短视频、多开标签页、后台 App 都会各自叠加;QUIC / HTTP3(如 YouTube)的每条 UDP 连接也各算一条。
- 所以单台设备正常上网的并发连接是几十到上百的量级。如果把上限当成“设备数”设成很小的值(比如 3、5),会直接导致网页打不开、图片加载失败。

短时超限通常表现为“部分请求卡住 / 加载失败”,过一会儿空闲连接释放后自动恢复,不会永久断网。

## 不同场景推荐的连接数

| 使用场景                       | 建议连接数                     | 说明                                                                         |
| ------------------------------ | ------------------------------ | ---------------------------------------------------------------------------- |
| 个人单设备(1 人 1 台手机/电脑) | 100 – 150                      | 覆盖正常网页 / 视频 / App 的并发峰值,并留足余量,不误伤                       |
| 个人多设备(手机 + 电脑 + 平板) | 200 – 400                      | 多设备同时在线,按每台约 100–150 估算叠加                                     |
| 家庭共享(4–6 台设备)           | 500 – 800                      | 多人多设备,含电视盒子 / IoT 等后台常驻连接                                   |
| 小型拼车(明确 N 人)            | 约 N × 150                     | 给每人留一台重度设备的余量;人数越少可留越宽                                  |
| 严格防转卖 / 防大量共享        | 预期设备数 × 100 起,再酌情收紧 | 目的是卡住“几十人共用一个号”的滥用,但仍要高于单人日常峰值,否则会误伤正常用户 |
| 不想影响体验 / 拿不准          | 0(不限)或 1000+                | 连接数是粗粒度防滥用手段;不确定就先不限,用流量 / 速度限制即可                |

以上是起步参考值。绑套餐后可在“流量信息 / 连接数”视图观察用户的实时并发连接,再按实际峰值上调——宁可设高一点,也不要因为设太低把正常用户挡在门外。

## 用户级覆盖

除了套餐级别的限速配置，还支持为单个用户设置独立的限速覆盖值，优先级高于套餐配置。

| 优先级 | 来源       | 说明                                                                     |
| ------ | ---------- | ------------------------------------------------------------------------ |
| 最高   | 用户覆盖值 | 用户管理中为单个用户设置的 speed_limit_override 和 device_limit_override |
| 默认   | 套餐配置   | 用户所属套餐的 speed_limit_mbps 和 device_limit                          |

## 自动推送时机

限速配置在以下场景自动推送到 Agent，无需手动操作：

| 触发事件       | 行为                                                                    |
| -------------- | ----------------------------------------------------------------------- |
| 服务器连接建立 | 内嵌 Xray 模式的 Agent 连接主控后，自动推送该服务器上所有用户的限速配置 |
| 用户套餐变更   | 用户绑定或切换套餐后，重新推送该用户的限速配置                          |
| 用户启用/停用  | 停用用户时移除限速配置（入站同时停用），启用时重新推送                  |
| 用户删除       | 推送移除该用户的限速配置                                                |
| 套餐到期       | 自动停用该用户的所有入站并移除限速配置                                  |

## 配置步骤

1. 确保目标服务器使用内嵌 Xray 模式（外置模式不支持限速）
2. 进入「套餐管理」页面，创建或编辑套餐
3. 在套餐表单中设置「下载限速 (Mbps)」和「最大设备数」
4. 保存套餐后，为用户绑定该套餐
5. 限速配置会自动推送到用户关联的所有内嵌 Xray 服务器

## 套餐完整参数

套餐除限速外还包含以下配置：

| 参数            | 说明                                          | 默认值      |
| --------------- | --------------------------------------------- | ----------- |
| 套餐名称        | 用于识别的套餐名称                            | \-          |
| 流量限额 (GB)   | 套餐总流量限额，超出后停用                    | 0（不限速） |
| 周期天数        | 流量重置周期                                  | 30          |
| 关联节点        | 限定该套餐可使用的节点范围                    | 全部        |
| 下载限速 (Mbps) | 单用户下载速度上限                            | 0（不限速） |
| 连接数限制      | 最大并发连接数(字段 device_limit)             | 0（不限速） |
| 流量统计模式    | 单向（仅上行或下行取大值）或双向（上行+下行） | 双向        |

## 注意事项

限速仅在内嵌 Xray 模式的服务器上生效。外置 Xray 模式的服务器不会接收限速推送，用户在这些服务器上不受速度限制。

修改套餐限速参数后需要等待下次推送时机（如服务器重连）才能在已连接的 Agent 上生效。建议修改后手动重启 Agent 或等待心跳自动推送。

连接数限制通过跟踪每个用户当前的活跃连接数实现:达到上限时新连接被拒绝,已有连接不受影响。它按“用户 + 物理节点”共享配额——同一用户在同一节点上的所有客户端/子账号合用一份。
