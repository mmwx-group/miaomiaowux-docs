## 核心功能

<CardGrid stagger>
  <Card title="远程服务器" icon="laptop">
    Master-Agent 架构，一键安装 Agent 接入，WebSocket / HTTP /
    轮询三种连接方式，卡片上直接启停 Xray、Nginx，远程升级 Agent。
    [了解远程服务器 →](/docs/remote-servers)
  </Card>
  <Card title="节点与入站向导" icon="setting">
    VLESS / VMess / Trojan / Shadowsocks / Hysteria2 / AnyTLS / Snell /
    Mieru，选协议、传输、安全层即可生成入站，自动同步为节点。 [了解节点管理
    →](/docs/nodes)
  </Card>
  <Card title="协议参考" icon="open-book">
    协议 × 传输 × 安全层完整矩阵，每种协议附向导截图与 Xray 配置示例。
    [查看协议矩阵 →](/docs/protocol-matrix)
  </Card>
  <Card title="证书管理" icon="approve-check">
    ACME 自动申请与续期，支持 Cloudflare / 阿里云 / 腾讯云 /
    Namesilo，自动部署到所有引用证书的服务器，也可上传或 Webhook 推送。
    [了解证书管理 →](/docs/certificates)
  </Card>
  <Card title="用户与套餐" icon="star">
    套餐定义流量、周期、限速与节点范围；用户可绑定多个套餐，一键复制订阅，支持
    Telegram 绑定与 Mini App。 [了解用户管理 →](/docs/users)
  </Card>
  <Card title="订阅与模板" icon="document">
    12+ 种客户端格式，V3 模板 include-all / filter
    语法让新节点自动进订阅，覆写规则精细分流。 [了解生成订阅 →](/docs/generator)
  </Card>
</CardGrid>
